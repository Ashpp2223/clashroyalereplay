# 原生战斗复盘实施计划

> 2026-10-09 用户选择改用模拟器，本计划重新作为当前运行时路线。此前的 [Windows 无 Android 计划](2026-10-03-windows-native-engine-integration.md)保留为研究记录。

日期：2026-09-23
依据：[设计文档](../specs/2026-09-22-native-engine-replay-design.md)

## 交付 1：固定引擎与可运行桥接

1. 固定上游提交到 `vendor/clash-royale-battle-engine`，记录提交和 SHA-256；核对本地运行时资产。
2. 在 `bridge/` 建立 Python 服务、运行时发现、模拟器/ADB 启动和探针连接。所有修改引擎的请求串行处理。
3. 建立桥接契约：状态/能力、重置、暂停、播放、速度、步进、出牌、快照、恢复、观测。确认动作后才发布事件。
4. 用假的探针服务做契约测试，再在可运行 ARM64 应用的 Android 设备或兼容模拟器上做标准卡组真实启动测试。

## 交付 2：v2 时间线

1. 在 `src/domain/nativeReplay.ts` 定义 v2 项目、动作、节点、草稿分支与校验。
2. 实现根到节点的动作链、创建检查点、删除子树、元数据编辑；任何历史动作不可覆盖。
3. 实现状态摘要和重放一致性检查；会话快照仅作为加速缓存。
4. 为旧 v1 载入、无环性、tick 单调性、动作顺序和分支保留编写测试。

## 交付 3：桌面集成与原生画面

1. Tauri 负责桥接进程生命周期、随机令牌、项目原子保存和恢复日志。
2. 通过兼容运行时的视频接口显示完整原生帧，并在 React 中建立敌方 HUD、竞技场、我方 HUD 三视口。当前先接 Android H.264 流；有 Emulator gRPC/WebRTC 的运行时再接低延迟路径。
3. 建立裁切矩阵、逆坐标映射和原生触摸/结构化动作入口；缩放和 DPI 下测试落点。
4. 将主界面切换到 v2 项目和原生画面，提供播放、步进、seek、节点、备注、保存/打开和错误状态。

## 交付 4：真实闭环验证

1. 在目标 ARM64 兼容运行时上验证本地已授权 APK、探针、内容包和版本指纹。
2. 双方各完成出牌；观察原生卡牌图和圣水 HUD；确认费用、手牌与事件日志一致。
3. 创建历史分支，跨分支恢复，应用冷启动后从动作日志重放；比较 digest。
4. 模拟视频和桥接中断，验证暂停及 journal 恢复。

## 后续里程碑

阶段 D 的自定义卡组、觉醒和英雄/精英能力必须先获得探针能力与真实回归证据，再开放 UI。阶段 E 处理冻结 sidecar 和安装包。

## 当前联调发现

- 本机已有 ARM64 AVD、SDK、预编译探针和同版本 `libg.so`。
- 本机现有原始 APK 的 SHA-256 为 `f76f3276dd1221361cd1a7ea71cbedbd4ef1c704cb681ec3a07dceabc7b65abf`，与上游声明的预制 APK 哈希不同，且不含 `libcrprobe.so`。真实引擎启动前需准备与上游基线匹配的 APK，或者验证可复现的探针注入流程。
- 已用本地重签名模板和固定探针构建出调试 APK，并检查其内 `libg` 与探针哈希。官方 ARM64 AVD 在本机 x86_64 主机上无法启动；下一步需要 ARM64 兼容 Android 设备或模拟器作真实回归。

## 2026-10-09 模拟器接入实施

- 保留现有 Tauri/React、Jason 精简客户端和固定探针；无需引入 AI 训练框架或另一套复盘界面。
- 构建改为从原版 APK 重新解包，补齐 `scid_sdk → libg → nativeBootstrapProbe` 加载顺序；核对库哈希和 APK assets 字节。生成了完整构建记录。
- 新增资源保留安装和恢复工具；实际覆盖签名不兼容替换、旧包回滚及资源校验。支持空实例原版安装和不含探针的兼容更新包，复盘启动始终要求匹配资源。
- MuMu 主程序和实例 0 已运行；root 得到用户明确授权。原版输入包在 Android 15 超时，在 Android 12 被外层加载器拒绝。兼容更新包在实例 0 已进入原版游戏更新画面；更新完成、匹配 `15.535.86` 和真实战斗仍需验收。实例 1 的 root 尚未授权，未修改。
- 快照恢复会清空旧分支在探针中的待执行动作；已有节点缓存和冷启动动作日志继续复用。
- 桥接启动核对选定实例，缺少工具或资源时保留可读错误；正常退出及失败清理本程序的网络规则和转发。Windows Tauri 浏览器来源已纳入固定 CORS 列表。
- 新增 `scripts/verify_native_runtime.py`，通过实际 HTTP 检查战斗、分支、快照、日志重放、播放和画面。未通过该脚本前，不能把代码或模拟测试通过当作原生战斗已完成。
