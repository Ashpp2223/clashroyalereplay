# 标准卡组桌面版使用说明

## 安装和首次连接

1. 运行 `皇室战争原生战斗复盘器_0.1.0_x64-setup.exe`。安装在当前用户下，应用已包含战斗连接服务和视频解码器，不需要另外安装 Python。
2. 没有模拟器的电脑会显示首次使用向导。阅读并接受 Android SDK 条款后，点击 **安装安卓运行环境**。应用从 Google 官方地址下载固定版本的最小运行组件，核验后安装专用的后台虚拟设备，无需预装 MuMu、Android Studio 或 Python。
3. 首次组件下载约 1.9 GB，安装目录至少留出 16 GB。默认使用当前用户数据目录；中文路径不兼容时，用 **更改安装位置** 选择可写的英文路径。电脑需要开启处理器虚拟化与 Windows Hypervisor Platform；向导会检查并提示，不会擅自修改系统设置。
4. 点击 **导入战斗资源包**，选择由匹配游戏文件准备的本地 ZIP，再点击 **开始连接**。公开安装包不包含游戏 APK、更新资源或用户账号数据，运行环境下载不会自动取得这些游戏文件。
5. 已有运行环境时，用 **设置运行环境** 选择含有 `runtime.json` 和 `prepared.json` 的目录。本机现有目录是 `C:\MyProject\皇室战争复盘记谱器\.local-runtime`；请保留其中的虚拟设备磁盘和游戏准备包。首次启动也会尝试识别本机已经准备好的这套环境。
6. 等待游戏启动和版本核验。成功后显示双方原生手牌、圣水和竞技场。版本不匹配时会禁止战斗编辑。界面采用老版记谱器的浅色蓝白风格，战斗画面随可用区域缩放。

## 创建和恢复分支

- 点击敌方或我方手牌，再点击竞技场出牌。只有被原生引擎确认的动作进入历史。
- 用播放、暂停、变速和前后步进控制时间。点击 **保存当前节点** 后战斗保持暂停。
- 选择旧节点后继续出牌，会形成另一条草稿分支；已有分支保留。
- 修改战斗名称、节点标题和备注后点击 **保存**。
- 默认项目位于用户数据目录；更换或卸载程序文件不会清理这些项目。重新打开应用时，会读取上次项目并恢复所选节点。
- 未提交的动作另存为恢复日志。出现恢复提示时，可恢复草稿或保留已提交节点。

## 中断与诊断

- 画面或连接异常后停止操作，点击 **恢复连接**。应用先恢复已保存节点，再读取草稿恢复日志。
- 桌面失联时，后台会自动暂停战斗。退出应用时会停止它创建的引擎和模拟器进程。
- 用 **导出诊断** 保存版本与运行状态；记录不包含会话口令或项目备注。
