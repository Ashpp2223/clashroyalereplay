# 原生战斗桌面版 0.3 使用说明

## 安装和首次连接

1. 运行 `皇室战争原生战斗复盘器_0.3.0_x64-setup.exe`。安装在当前用户下，应用已包含战斗连接服务和视频解码器，不需要另外安装 Python。
2. 没有模拟器的电脑会显示首次使用向导。阅读并接受 Android SDK 条款后，点击 **安装安卓运行环境**。应用从 Google 官方地址下载固定版本的最小运行组件，核验后安装专用的后台虚拟设备，无需预装 MuMu、Android Studio 或 Python。
3. 首次组件下载约 1.9 GB，安装目录至少留出 28 GB。默认使用当前用户数据目录；中文路径不兼容时，用 **更改安装位置** 选择可写的英文路径。电脑需要开启处理器虚拟化与 Windows Hypervisor Platform；向导会检查并提示，不会擅自修改系统设置。
4. 点击 **导入战斗资源包**，选择由匹配游戏文件准备的本地 ZIP，再点击 **开始连接**。公开安装包不包含游戏 APK、更新资源或用户账号数据，运行环境下载不会自动取得这些游戏文件。
5. 已有运行环境时，用 **设置运行环境** 选择含有 `runtime.json` 和 `prepared.json` 的目录。本机现有目录是 `C:\MyProject\皇室战争复盘记谱器\.local-runtime`；请保留其中的虚拟设备磁盘和游戏准备包。首次启动也会尝试识别本机已经准备好的这套环境。
6. 等待游戏启动和版本核验。成功后显示双方八张牌序、圣水和原生竞技场。版本不匹配时会禁止战斗编辑。界面采用老版记谱器的浅色蓝白风格，战斗画面随可用区域缩放。

## 创建存档与初始配置

- 点击 **新建存档**，填写名称，分别选择双方八张卡、觉醒或精英形态，并用前移/后移按钮调整牌序。第 1～4 张是起手牌，第 5～8 张是待抽牌。
- 新战斗默认双方卡牌、国王塔和公主塔均为 **16 级**。点击 **创建存档并开始** 后，引擎回读确认牌序，再创建项目文件。
- **初始卡组、牌序、等级和种子只在创建时设置。** 创建后入口变为 **初始配置（只读）**；保存层也会阻止修改同一份存档的初始配置。需要另一个初始局面时，新建存档。
- 没有已有项目时，运行环境就绪后等待用户创建，不会自动生成标准卡组存档。
- 本版本的新存档使用固定种子 41，普通牌序由原生引擎实际发牌校准；镜像或圣水采集器单张固定在第 8 位，同时携带时固定在第 6、8 位。这些特殊位置遵守已验证的原生发牌行为。
- 每方最多两张觉醒、两张精英，合计最多三张特殊形态；觉醒次数和技能冷却继续由原生引擎决定。
- 双方牌栏显示实际四张手牌和待抽顺序。待抽牌不可直接使用；单位仍在场或补牌期间，按引擎实际返回的状态显示。
- 旧存档沿用原来的等级与发牌规则，已有局面不重写。

## 创建和恢复分支

1. 选择要继续的节点，点击 **从当前节点创建子节点**，会复制当前局面并选中新的子节点；同一时刻也可以复制。
2. 点击敌方或我方手牌，再点击竞技场落点。只有原生引擎确认的出牌或技能进入历史。
3. 点击 **保存当前节点** 或右上角 **保存**，会把进度保存到正在编辑的子节点，不额外增加一层。已经产生后代的历史节点保留；从它继续保存会另建分支。
4. 点击树中的节点恢复局面。拖动节点调整位置，拖动空白移动视图，滚轮缩放，**适应视图** 查看整棵树。节点位置会保存。

- 播放、暂停、变速、前后步进和时间条控制原生时间。保存节点后保持暂停。
- **存档** 显示项目名、保存时间和节点数，可选择存档目录、打开项目。第一版手工局面存档有明确标记，需要用保留的旧版程序打开。
- 战斗名称、节点标题和备注可直接修改，点击 **保存** 写入文件。
- 再次启动恢复上次项目及所选节点；未提交的出牌保存在草稿日志中，可在提示时恢复。
- 从已知标准版升级时，程序先核对引擎和重放摘要，再另存“升级副本”。原文件不覆盖；未知引擎版本不自动迁移。

## 中断与诊断

- 画面或连接异常后停止操作，点击 **恢复连接**。应用先恢复已保存节点，再读取草稿恢复日志。
- 桌面失联时，后台会自动暂停战斗。退出应用时会停止它创建的引擎和模拟器进程。
- 用 **导出诊断** 保存版本与运行状态；记录不包含会话口令或项目备注。

## 当前范围和验证状态

2026-10-10 在本机独立 Android SDK 设备中，当前固定资源版本的 122 张基础卡、42 种觉醒、24 种精英形态全部完成真实引擎出牌确认。卡牌矩阵已按默认的双方卡牌与塔均为 16 级重测，证明出牌形态被消费，不代表每张卡的全部交互组合均已覆盖。

竞技场保持原生渲染，牌栏使用老版卡图界面。视频传输改为 720×1280、最多 30 帧/秒，桌面只绘制竞技场，减少解码与绘制开销。实际流畅度仍与电脑图形模式有关。

标准版已经完成独立 SDK、新建空设备、资源导入、真实战斗和关闭重开恢复。本机验证不能代表已经覆盖所有电脑；首次启动仍需要加载安卓和游戏资源。

虚拟设备默认内部存储为 20 GB。升级前会检查其剩余空间；安装请求被拒绝且原包完整时保留原安装，不为回滚而卸载。2026-10-10 本机旧设备已从 10 GB 保留数据扩至 20 GB，恢复全部 656 份更新资源，并以新探针准确重放原节点至 tick 298。

0.3.0 已通过独立应用实例的完整脚本验收：创建配置、精确牌序、只读保护、复制/出牌/原地保存、关闭重开和存档列表。验收不移动系统鼠标，并生成七张界面截图。
